# Valid Parentheses

**Difficulty:** `Easy`

## Problem

Given a string s containing just the characters '(', ')', '{', '}', '[', and ']', determine if the input string is valid. A string is valid if every opening bracket is closed by the same type of closing bracket, and brackets are closed in the correct order.

Read the string s from standard input. Print "true" if it is valid, otherwise "false".

## Examples

### Example 1

**Input**
```
()[]{}
```
**Output**
```
true
```

**Explanation:** Every bracket is matched correctly in the right order.

### Example 2

**Input**
```
([)]
```
**Output**
```
false
```

**Explanation:** The order is wrong: '(' was opened before '[', so it must close after '[', not before.
